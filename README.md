# Rohini Bramhane Portfolio

## Run locally
Open `index.html` in a browser.

## Customize before submission
1. Replace `your.email@example.com` with your actual email.
2. Replace the GitHub and LinkedIn links with your profiles.
3. Add real project links/screenshots if available.
4. Review education wording and update the college name/year if required.

## Deploy on GitHub Pages
Create a GitHub repository, upload these three files, then open:
Settings → Pages → Deploy from branch → main → /(root) → Save.
